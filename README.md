# Registro de Incidencias by SARA PORTILLO

## Propósito

**RegistroIncidencias** es una aplicación móvil para Android que permite al usuario registrar una incidencia de manera sencilla mediante un título y una descripción breve.

La aplicación cuenta con una pantalla principal donde el usuario puede ingresar la información de la incidencia y presionar el botón **"Crear Reporte"**. Al hacerlo, se muestra un mensaje de confirmación indicando que el reporte fue creado.

## Funcionalidades actuales

La aplicación permite:

* Ingresar el **título de la incidencia**.
* Ingresar una **descripción breve** de la incidencia.
* Presionar el botón **"Crear Reporte"**.
* Mostrar un mensaje de confirmación con el título de la incidencia.
* Mostrar el mensaje de confirmación en **color verde y negrita**.
* Limpiar automáticamente los campos de título y descripción después de crear el reporte.
