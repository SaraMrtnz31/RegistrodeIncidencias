# Registro de Incidencias by SARA PORTILLO

## Propósito

RegistroIncidencias es una aplicación móvil para Android que permite al usuario ingresar y registrar una descripción de una incidencia de forma sencilla.

Actualmente, la aplicación cuenta con una pantalla principal donde el usuario puede escribir una incidencia y presionar el botón **"Registrar incidencia"**, mostrando un mensaje de confirmación.

## Herramientas utilizadas

* Android Studio
* Kotlin
* Jetpack Compose
* Git
* GitHub

## Estado actual

**Funcionando:**

* Interfaz principal de la aplicación.
* Campo para ingresar la descripción de una incidencia.
* Botón para registrar la incidencia.
* Mensaje de confirmación.

**Pendiente:**

* Guardar las incidencias de forma permanente.
* Implementar una base de datos.
* Mostrar y administrar las incidencias registradas.

## Cómo abrir el proyecto

1. Abrir Android Studio.
2. Seleccionar **Open**.
3. Elegir la carpeta del proyecto `RegistrodeIncidencias`.
4. Esperar la sincronización de Gradle.
5. Ejecutar la aplicación en un emulador o dispositivo Android.
